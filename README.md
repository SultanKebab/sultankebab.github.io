# Sultan Website

Fertige statische Website für GitHub Pages oder Cloudflare Pages.

## Veröffentlichung mit GitHub Pages

1. Den gesamten Inhalt dieses Ordners in ein öffentliches GitHub-Repository hochladen.
2. In GitHub `Settings` → `Pages` öffnen.
3. Unter `Build and deployment` die Quelle `Deploy from a branch` wählen.
4. Branch `main` und Ordner `/ (root)` auswählen und speichern.

`index.html` liegt bereits im Hauptverzeichnis. Die Bildnamen und internen Verlinkungen sind für GitHub vorbereitet.
